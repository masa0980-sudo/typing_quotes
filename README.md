# 名言タイピング（Quote Typing）

偉人たちの名言をお題に、タイピングの**正確さと速さ**を競うブラウザゲーム。

公開URL: https://masa0980-sudo.github.io/typing-quotes/

## 遊び方

1. タイトル画面で **日本語 / English** のモードを選ぶ
2. START を押すと3カウントの後に開始
3. 表示されたお題を打ち切ると次の問題へ。全5問で1ゲーム
4. 結果画面で 正確率・速度（KPM / WPM）・スコア・ランクが出る

`Esc` でいつでもタイトルへ戻れる。

## 2つのモード

| モード | お題 | 打つもの |
|---|---|---|
| 日本語 | 名言の日本語文（漢字かな交じり） | ローマ字 |
| English | 名言の英語原文 | 英語そのまま |

日本語モードは、同じかなに対する複数のローマ字表記に対応している。

- `し` = `shi` / `si` / `ci`
- `つ` = `tsu` / `tu`
- `ん` = `nn` / `n` / `xn`（ただし次が母音・な行・や行のときは `n` 単独は不可）
- `きっと` = `kitto` / `kixtuto` / `kiltuto`
- `しゃ` = `sya` / `sha`
- `ー` = `-`、`、` = `,`、`。` = `.`

## 名言データについて

`src/lib/quotes.ts` に **43件・38人分**を収録。各項目は次を持つ。

| フィールド | 内容 |
|---|---|
| `ja` | 日本語文（表示用） |
| `kana` | 上のひらがな読み（ローマ字判定用） |
| `en` | 英語（欧米の偉人は原文、日本の偉人は英訳） |
| `author` / `authorEn` | 人物名 |
| `role` | 肩書き |
| `origin` | もともと何語で語られたか |

内訳は 日本の偉人11／政治・社会8／発明・科学7／哲学・思想7／芸術・文学5／逆境・挑戦5。

**「狂気とは同じことを繰り返し、違う結果を期待することだ」（アインシュタイン）のように、
広く出回っているが本人の言葉として出典を確認できないものは意図的に除いてある。**

名言を追加するときは `quotes.ts` に1件足すだけでよい。`kana` はひらがな・`ー`・`、`・`。`
だけで書くこと（漢字やカタカナが混ざるとローマ字に展開できない）。

## スコア

```
KPM   = 正しい打鍵数 / 経過分
スコア = KPM × 正確率² × 10
```

正確率を2乗で効かせているので、速いだけ・正確なだけでは伸びない。

## 開発

```bash
npm install
npm run dev     # http://localhost:3000
npm run build   # 静的エクスポート → out/
```

- **Next.js 16 / React 19 / TypeScript / Tailwind CSS v4**
- 効果音は Web Audio API で合成（音源ファイル不要）
- `main` ブランチへ push すると GitHub Actions が自動でビルドして Pages へ公開する
