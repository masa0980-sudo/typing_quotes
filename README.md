# 名言タイピング（Quote Typing）

偉人と一流の名言をお題に、タイピングの**正確さと速さ**を競うブラウザゲーム。

公開URL: https://masa0980-sudo.github.io/typing_quotes/

## 遊び方

1. タイトル画面で **日本語 / English** のモードを選ぶ
2. START を押すと3カウントの後に開始
3. 打ち切ると **発言者の肖像・出典・背景の解説** が出る（Enter / Space で次へ）
4. 全5問を終えると、正確率・速度（KPM / WPM）・スコア・ランクが出る

`Esc` でいつでもタイトルへ戻れる。

## 2つのモード

| モード | お題 | 打つもの |
|---|---|---|
| 日本語 | 名言の日本語文（漢字かな交じり） | ローマ字 |
| English | 名言の英語原文 | 英語そのまま |

日本語モードは、同じかなに対する複数のローマ字表記に対応している。

- `し` = `shi` / `si` / `ci`
- `つ` = `tsu` / `tu`
- `ん` = `nn` / `n` / `xn`（ただし次が母音・な行・や行のときは `n` 単独は不可）
- `きっと` = `kitto` / `kixtuto` / `kiltuto`
- `しゃ` = `sya` / `sha`
- `ー` = `-`、`、` = `,`、`。` = `.`

## 名言データについて

`src/lib/quotes/` に **115件・71人分**を収録。分野ごとにファイルを分けてある。

| ファイル | 件数 | 内容 |
|---|---|---|
| `science.ts` | 18 | エジソン、アインシュタイン、キュリー、ニュートンなど |
| `philosophy.ts` | 18 | ソクラテス、孔子、老子、セネカ、カントなど |
| `society.ts` | 18 | リンカーン、ガンジー、マンデラ、キング牧師など |
| `arts.ts` | 14 | シェイクスピア、ゴッホ、ダ・ヴィンチ、モーツァルトなど |
| `japan.ts` | 20 | 福沢諭吉、坂本龍馬、渋沢栄一、北斎、利休など |
| `short.ts` | 17 | 短くて打ちやすい名言（読み20字前後） |
| `modern.ts` | 10 | 現代の実業家・クリエイター（ヒカル） |

読みが22字以下の短い問題が23件あり、初心者でも遊びやすいようにしてある。

各項目は次を持つ。

| フィールド | 内容 |
|---|---|
| `ja` | 日本語文（表示用） |
| `kana` | 上のひらがな読み（ローマ字判定用） |
| `en` | 英語（欧米の偉人は原文、日本の偉人は英訳） |
| `author` / `authorEn` | 人物名 |
| `role` | 肩書き |
| `origin` | もともと何語で語られたか |
| `source` | 出典（書名・演説名など） |
| `note` | 意味と背景の解説。打ち終わったあとに表示される |

**「狂気とは同じことを繰り返し、違う結果を期待することだ」（アインシュタイン）のように、
広く出回っているが本人の言葉として出典を確認できないものは意図的に除いてある。**

名言を追加するときは、分野に合うファイルに1件足すだけでよい（`quotes/index.ts` が自動でまとめる）。
`kana` はひらがな・`ー`・`、`・`。` だけで書くこと（漢字やカタカナが混ざるとローマ字に展開できない）。

`source` は分かる範囲で正確に書く。書名や演説名が特定できないものは
「〜の言葉として広く伝わる」のように、**断定を避けた書き方にすること**
（もっともらしい出典をでっち上げない）。

## 発言者の肖像

打ち終わった画面に、その言葉を残した人の顔が出る。画像は Wikimedia Commons から取得して
128px に切り出したもので、`public/portraits/` に置いてある。

71人ぶんを収録。うち11人はクレジット表示が必要なCCライセンスなので、
タイトル画面の **「画像クレジット」** に作者・ライセンス・出典を掲載している
（CC BY / CC BY-SA の表示義務を果たすための画面で、内容は自動生成）。

肖像が用意できない人はイニシャルの円で表示される（現在は該当なし）。

```bash
python3 scripts/fetch-portraits.py   # 取得しなおす(要ネットワーク)
```

## スコア

```
KPM   = 正しい打鍵数 / 経過分
スコア = KPM × 正確率² × 10
```

正確率を2乗で効かせているので、速いだけ・正確なだけでは伸びない。

## 開発

```bash
npm install
npm run dev       # http://localhost:3000
npm run build     # 静的エクスポート → out/
npm run validate  # 名言データの検証(打てない文字が無いか等)
```

- **Next.js 16 / React 19 / TypeScript / Tailwind CSS v4**
- 効果音は Web Audio API で合成（音源ファイル不要）
- `main` ブランチへ push すると GitHub Actions が自動でビルドして Pages へ公開する
